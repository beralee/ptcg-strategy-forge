# Public SDK update — 2026-10-07

This release publishes the reviewed Forge SDK overlay on the existing public
snapshot. It includes immutable `PublicDecisionView` queries, versioned public
input v2/v3, explicit coverage and training-input gates, public event history
and recovery, Base observation and semantic transaction helpers, and bounded
shared resource planning helpers. These are SDK mechanisms, not an authored
deck strategy or a trained model.

## Use the public input SDK

```python
from ptcg_strategy_forge import PublicDecisionView, PublicInputV3, PublicHistoryV3

value = PublicInputV3.capture(raw_observation)
view = PublicDecisionView(raw_observation)
coverage = view.input_coverage()
abilities = view.ability_ledger()
effects = view.effect_ledger()
context = view.interaction_context()
memory = PublicHistoryV3()
memory.ingest(value.history())
restored = PublicHistoryV3.restore(memory.export())
```

`raw_observation` is the versioned `{profile, frame, input}` envelope provided by
a compatible Host. The existing CABT transport is a separate contract. Rebuild
the view after every accepted choice. Only indexes from the current immutable
`select.option` frontier may be submitted. Base/Host still owns legality,
mandatory/terminal protection, hard tiers, veto and final commit.

```powershell
python forge.py public-input --input <public-observation.json>
python forge.py public-input --input <public-observation.json> --require-training public-observation-v3
python tools/build_public_input_v3_contract.py --check
python tools/build_sdk_snapshot.py --check
python forge.py check --workspace demo/marnie-forge
```

Missing data remains tagged unknown or unsupported. Legacy frames can still be
read but cannot claim v3 training qualification. `public-observation-v3` permits
explicitly masked partial semantics with the required complete public event
prefix; `semantic-complete-v3` remains rejected while effect coverage is partial.
Neither qualification means that a new deployed tensor profile or trained actor
has been supplied.

## Included scope

- Closed public schemas, typed facts, immutable entity/attack/energy queries,
  ability and quota ledgers, effect and interaction context, and event recovery.
- Optional shared current-window resource planning and semantic goal helpers;
  future suffixes are conditional proposals, never executable authority. Values
  are bounded heuristic estimates, not probabilities or full game simulation.
- A pinned package-capacity extension for compatible loaders. Existing client
  compatibility must be checked separately; this does not deploy a new Host.
- Godot public projection reference modules and isolated-runtime integration
  tools. These are not a complete engine checkout or a production client.
- Public input witnesses from constructed positions followed by actual engine
  operations. Their original source hashes and scope are preserved under
  `evidence/public-input-v2` and `evidence/public-input-v3`. They are not private
  battle replays, private curricula, or strength benchmarks.

The evidence includes 29 v2 snapshots and 49 v3 snapshots. SDK regressions read
these artifacts and verify their public schemas and selected source hashes.
This publication does not rerun the original native engine sessions, claim a
complete engine, CABT parity, device acceptance, or production approval.

## Publication boundary

No new personal deck templates, authored strategy builders, strategy packages,
private replay banks, trained actors, account credentials or signing keys are
included. Previously published demonstration fixtures remain unchanged. Local
learning pipelines and private strategy research stay outside this update.

The source snapshot generator records the reviewed origin and hashes every
included vendor and native-reference byte. Existing remote commits are retained.
The public predecessor is `4dd40d0`; reverting this publication restores that
public SDK baseline without touching local private workspaces.
