# 本机训练和对局的稳定性保护

用于本机重型任务的启动、恢复和扩容；正常文档编辑、轻量合同测试不需要启动训练监控。数值是这台 64 GiB Windows 研发主机的保守门槛，不是模型质量指标或对其他机器的普适保证。

## 启动前

- 检查当前 Python、Godot headless 等重型任务，采用机器级互斥锁串行排队。其他任务也可能占用资源；不能仅统计本会话。正常使用中的游戏/编辑器不应被终止，但其占用计入系统压力。
- 可用物理 RAM 至少 12 GiB，系统提交使用率必须低于 70%。最多 4 workers，未知规模从 1 开始。不得通过环境变量提高已有 PTCGABC 安全上限。
- 检查**实际输出盘、实际分页文件所在盘、系统盘、TEMP/TMP 盘**。输出/分页盘启动前至少 20 GiB，系统/临时盘至少 5 GiB；多角色同盘使用最严格门槛。预估数据、轨迹、导出、运行时副本及原子写入临时文件的总增量，不以物理 RAM 充足替代磁盘检查。
- 每次写明局数/epochs、worker 数、最长时长、输出量上限、输入与恢复身份。默认每个运行目录最多 2 GiB；超过时拆成有界分片，保留原实验分母和切分，不静默删旧分片。Forge 当前本地运行器最大 90 分钟，BC 子进程最多 30 分钟。
- 先通过合同/安全测试，再做 1–2 局或小型训练试运行。发生过卡死时，先保存系统事件、任务退出记录与原始失败产物；不能在原因和资源状态尚未检查时直接重启大任务。

## 运行中

- 使用独立监督进程管理计算子进程，约每 2 秒采样：时间、可用 RAM、提交量/上限、相关磁盘余量、本任务进程树的私有内存、全机主要内存占用进程及输出字节数。采样以追加日志持久化，失败样本也保存；不记录完整命令行、凭据或私有对局内容。
- commit ≥70%、RAM <12 GiB、输出/分页盘 <10 GiB、系统/临时盘 <3 GiB 时停止。额外限制单个任务进程私有内存 >8 GiB、任务进程树 >12 GiB、超过预定输出量或时长。探针/日志不可用时 fail closed，不假定资源正常。
- 停止范围仅限监督器拥有的任务子树；不得按进程名称杀掉所有 Python/Godot，不动用户编辑器、其他任务或系统分页文件。失败回执明确列出触发条件，保留已完整写入的分片。
- 小模型 CPU 训练/推理使用 1 个数学库线程，任务以较低优先级运行。GPU 任务只有在用户范围包含、并具备 VRAM/温度等相应监控时才启动；CPU 监控不能冒称已经覆盖 GPU、散热、电源或所有驱动故障。
- 资源故障不自动重试；先缩小明确预算或恢复资源并复核。只等待其他任务释放互斥锁也应有时间上限，不用重试绕过低内存、低磁盘或未知探针。

## 写盘与验收

- 汇总/完成清单先写同盘临时文件，flush、校验字节/JSON 后原子替换；完整运行的清单最后发布。半写 checkpoint、临时导出、零字节轨迹、截断 JSON 不具备恢复或训练资格。
- 引擎 trace 每次追加检查写入结果，失败立即终止本运行；每局结束重新验证文件 hash、链和计数。成功退出码不能替代这些验证。
- 输出目录不可覆盖。资源、写盘或监控失败保留在计划分母中并标为 failed；不要删掉失败局后报胜率。基线/候选需同一冻结运行时，保护层改变了运行时摘要时双方都重跑；不改变候选来迎合已看过的确认结果。
- 只清理当前用户明确授权范围内、已确认可再生成的缓存/临时产物；先验证绝对路径、目录联接、活动进程和保护清单，保留删除回执。不把“文件旧/目录大”当作“无用”，不自动删模型、数据集、有效实验、源码、Git 历史或回滚包。

## 当前 Forge 接入点

- `src/ptcg_strategy_forge/resources_gate.py`：机器级互斥、启动内存/磁盘准入。
- `src/ptcg_strategy_forge/run_safety.py`：磁盘门槛、进程树私有内存、输出/时长预算、监督与原子 JSON。
- `tools/neural_strategy_research.py train`：受监督的 CPU BC 子进程；内部 worker 参数不是独立训练入口。
- `tools/local_engine_bench.py`、`tools/research_io.gd`：受监督 Godot、校验写盘和完整轨迹验收。
- 旧研究脚本或其他仓库不自动获得以上保护；使用前核对实际调用链。不要用文档中的未来能力补齐不存在的监控。

证据至少含 `resource-admission.json`、`resource-telemetry.jsonl`、结束状态/异常回执、输出上限和实际用量，以及测试过哪些触发条件。资源正常的启动快照不能证明整个运行期一直正常。
