# 数据诊断与持续迭代

用于已有 BC/混合策略的下一轮研发：冻结输入 → 查覆盖与混淆 → 审核真实改选 → 补合格数据/表达 → 受控训练 → 原生工程验收 → 新确认组 → 晋级或回滚。任务边界、Base 权威和电脑稳定性要求保持不变。

## 先定位瓶颈

核对样本数、独立对局组数、教师身份、对手/牌表、context、动作类别、训练/验证标签分布、缺失特征、重复和冲突。分别统计当前合法候选、Base 授权候选、模型调用与改选；调用率不是优化目标。

分别报告每类动作的教师一致率、经审核的语义一致率、负对数似然/校准和关键战术案例。总体 top-1 掩盖稀缺动作，也不代表动作正确率。检查学习曲线；验证损失恶化时不靠增加 epoch 宣称进步。

区分：输入无法区分 → 修投影或受审特征；示范覆盖不足 → 定向收集；同输入标签冲突/可互换 → 审核标签。复制已有样本或任意扩大模型不能自动修复这些问题。

## 改选不等于错误

- 同一张牌的可互换实体副本、可交换的动作顺序、不同资源路线分别审核。先看完整行动链、攻击窗口与后续资源，再定标签。
- 首个分歧是复盘入口，不是败因证明。赢局也可有劣选，败局也可有好动作。保留改善局，避免纠错时抹掉有益探索。
- 延后附能、场地等统计须注明单位是窗口、去重回合还是对局；同一回合可多次推迟。随后出现同类动作不等于完成原目标，也不证明该顺序更好。保留目标身份和完整回合供复核。
- 改选账本记录策略/对手/运行时、相关组、窗口/观察、原模型动作、同窗规则建议、后续公开事件、判断及依据。分类：证据支持的劣选、可接受等价/可交换、有益、信息不足。未审核或仅由整局胜负推断的判断不进入强监督标签。
- 张量相同不是动作等价证明，可能遗漏目标身份、进化时机或资源差异。只有经过语义审核的可互换选择才允许多正例或合并；不同后排实体不能因 HP/能量相同就合并。保留原始映射，选项重排后重绑定。
- 同窗规则查询只能标记教师建议，不能冒称已执行或最优。规则/人工意见分歧保留来源。计划后缀标签来自确实执行的合格轨迹，查询只有当前动作时不造后续教师标签。

## 有目的地扩数据和表达

按缺口预注册教师与对手、权重、seed 分组和分片预算。可先以几十局确认多对手资格，再扩至数百局；具体局数跟随任务和覆盖，不是通用质量门槛。每片通过完整性与覆盖后再继续，失败原样保留。跨对手提取只取目标教师座位，不能把对手的私有观察或不同 UID 词表作为目标样本；镜像双方须明确身份、去重和分组。

混合教师状态与模型访问状态中的审核查询。保留标签 provenance，先按所有相关轨迹分组切分再增广。用于改模的确认集转为诊断；下一候选另封新确认组。

特征从公开规则和资源依赖出发，例如进化前置、能量缺口、后继攻击手、奖赏路线、目标价值、场地机会成本。当前张量能推导的关系可在 Actor 内编码；需要新增信息时版本化投影并做 Python/Godot 对照，不把未来观察、隐藏信息或教师评分偷渡成输入。未知结果保留未知。

可加入仅训练使用的行动族、公开资源变化或 outcome 辅助头；部署仍只看当前授权输入。GBDT 可作特征诊断或额外教师，但重复同一批弱标签不自动提高教师质量。公开参赛模型、录像和本地精确牌表须重新做 identity/合同映射。

## 受控比较与晋级

预先指定假设、主要指标和候选选择规则。同数据比较特征/目标改动，或同模型比较数据改动；同时改动时安排能分离贡献的消融。记录每次尝试，不只保留最优结果。

相同随机 seed 不保证不同输入维度的基础权重相同：新增维度会改变 fan-in 缩放及后续 RNG 序列。能做匹配对照时保留基础权重，零初始化新增关系并验证其可获非零梯度；单个初始化的结果仍不能证明普遍收益。

规则、上一 Actor 和新 Actor 使用冻结对手/权重、相关 seed 与双座位。开发集找问题，最终包冻结后在新确认集验收；按种子聚类报告不确定性与每类对手退化。小样本不确定时保留结论，不事后换指标或无上限补局直到显著。

隔离运行时应复制实际受哈希约束的 native/loader 文件，不能通过目录联接跟随其他任务的构建编辑。运行前后摘要漂移时整片拒收，保留失败，修复隔离后在新目录重跑；未采用的重复不能累计为新增独立样本。

先通过完整性、原生调用、隐私/合法性及部署性能，再讨论强度。晋级与退化约束在看确认结果前固定；未通过则交付研发候选、分析缺口并保留旧默认。能运行、模仿更像、实战更强是独立结论。

PPO 只在任务包含整局 RL 且 rollout/log-prob/value/reward/终局与版本闭合后启动。先小型对手池和一次更新验收，再决定规模；公开方案的大机器吞吐不代表本机预算。

## 本地经验的使用方式

当前 Forge 的 `tools/neural_strategy_research.py train --variant exact|equivalent|relations` 提供单标签、多正例和多正例加公开资源关系的对照入口。资格与等价证明在 `neural_dataset.py`；八项关系在 `neural_relations.py`，仅使用既有 128/32 张量。换版本先核对实际代码与 `--help`。单张牌的未知属性费用不能由能量数量差充当已支付证明。

2026-09-19 玛俐 0.1.2 分析发现：357 条训练全为主行动/镜像；贴能、进化一致率比攻击低；84 次改选初筛有 8 次仅实体副本字段不同，严格核对当前手牌、UID 和交互后仅 5 次获等价资格，其余 79 次保留未知。22 次延后贴能中 18 次当回合仍贴能。这是按行动链审核的实例，不能据此永久强制先贴能、固定场地或给未来任务规定相同样本量。证据在对应工作区 `research/CONTINUOUS-IMPROVEMENT.md`、`learning-gap-analysis.json` 和 R3 的 `historical-review-ledger.json`；方法来源见 [研究来源](research-sources.md)。
